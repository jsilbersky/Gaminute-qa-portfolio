# Postman API Testy

Tato složka obsahuje exportovanou kolekci automatizovaných API testů pro projekt Gaminute. Testy ověřují funkčnost a stabilitu produkčního API.

## 📁 Obsah
* `Gaminute - Production API.postman_collection.json` - Kompletní kolekce obsahující requesty a testovací skripty (validace status kódů, odezvy, struktury JSON a základní business logiky).

## 🚀 Jak testy spustit
1. Stáhněte a nainstalujte si aplikaci [Postman](https://www.postman.com/downloads/).
2. V aplikaci klikněte v levém panelu na tlačítko **Import**.
3. Nahrajte soubor `Gaminute - Production API.postman_collection.json` z této složky.
4. V záložce *Collections* se vám objeví nová kolekce. 
5. Můžete si prohlédnout jednotlivé requesty a jejich testy, nebo spustit všechny najednou kliknutím na tři tečky u názvu kolekce a výběrem **Run collection**.
